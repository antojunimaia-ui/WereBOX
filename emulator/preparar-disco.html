reDOS · bancada: preparar o disco C:

Este utilitário sobe o MS-DOS 6.22 real (disquete de boot da ISO) com um disco em branco (Systems/MS-DOS 6.22/novo.img, gerado por tools/mkdisk.mjs) e deixa o próprio DOS formatar e instalar: FORMAT C: /S + XCOPY. A imagem pronta sai em Systems/MS-DOS 6.22/c.img. Rode npm run serve (o endpoint de gravação só existe nele).
